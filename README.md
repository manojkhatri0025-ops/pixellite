# PixelLite

Free browser-based image compression. Images are never uploaded by the tool.

Live site: https://manojkhatri.name.np/pixellite/

## Hosting
GitHub Pages: deploy from main, /(root). No dependencies or build step.

## Search
Sitemap: https://manojkhatri.name.np/pixellite/sitemap.xml
Canonical URL and social metadata are in index.html. The sitemap lists the single actual page; section anchors are not separate pages.
Robots rules are effective only at the host root. For this project site, add its sitemap to the existing domain-root robots.txt while preserving existing rules. Submit the sitemap in Google Search Console after verifying the URL-prefix property. Indexing is not guaranteed.

## Updating
Edit files and commit to main. If the public URL changes, update the canonical URL, Open Graph URLs, JSON-LD, sitemap.xml and 404.html together.
